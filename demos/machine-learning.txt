Machine learning is the study of algorithms that improve at a task by learning from data instead of following hand-written rules. In supervised learning, a model learns from labeled examples, such as photos tagged with the object they contain. Regression predicts continuous values, like house prices, while classification predicts discrete categories, like spam or not spam. Linear regression fits a straight line that minimizes the squared error between predictions and targets. Logistic regression turns a linear score into a probability using the sigmoid function. Decision trees split the data on feature thresholds to make predictions that are easy to interpret. Random forests average many decision trees trained on random subsets to reduce overfitting. Gradient boosting builds trees one after another, each correcting the errors of the previous ones. Support vector machines find the boundary that separates classes with the widest possible margin. The k-nearest neighbors algorithm classifies a point by a vote among the closest training examples.

Unsupervised learning finds structure in data without any labels. K-means clustering groups points around a fixed number of centers that it moves iteratively. Principal component analysis compresses data by projecting it onto the directions of greatest variance. UMAP and t-SNE squeeze high-dimensional data into two or three dimensions while keeping neighbors close. Anomaly detection flags rare examples that look unlike the rest, such as fraudulent transactions. Autoencoders learn to compress inputs into a small code and reconstruct them from it.

Overfitting happens when a model memorizes the training data and fails on new examples. Underfitting happens when a model is too simple to capture the pattern in the data. The bias-variance tradeoff describes the tension between models that are too rigid and models that are too flexible. Regularization, such as L2 weight decay, penalizes large weights to keep models simpler. Cross-validation estimates performance by training and testing on different splits of the data. A held-out test set must never be used for choosing hyperparameters, or the evaluation becomes optimistic. Precision measures how many predicted positives are correct, while recall measures how many real positives were found. Data leakage occurs when information from the test set sneaks into training and inflates the score.

A neural network is built from layers of artificial neurons, each computing a weighted sum followed by an activation function. The ReLU activation outputs zero for negative inputs and passes positive inputs unchanged. Backpropagation uses the chain rule to compute how each weight contributed to the error. Gradient descent nudges every weight a small step in the direction that reduces the loss. The learning rate controls how big each step is, and a poor choice can make training diverge. Stochastic gradient descent estimates the gradient from small random batches, which is faster and adds helpful noise. The Adam optimizer adapts the learning rate for each parameter using running averages of gradients. Dropout randomly switches off neurons during training so the network cannot rely on any single path. Batch normalization rescales activations inside the network, which stabilizes and speeds up training. Deep learning took off around 2012 when AlexNet won the ImageNet competition using GPUs.

Convolutional neural networks slide small learned filters across an image to detect edges, textures, and shapes. Pooling layers shrink feature maps and make the network tolerant to small shifts. Residual connections in ResNet let signals skip layers, making it possible to train networks with hundreds of layers. Transfer learning reuses a network pretrained on a large dataset and fine-tunes it for a new task. Object detection models such as YOLO draw boxes around every object in a single pass. Diffusion models generate images by learning to reverse a process that gradually adds noise.

Word embeddings represent words as vectors, so that words with similar meanings sit close together. Recurrent neural networks process sequences one step at a time while carrying a hidden state. The transformer architecture replaced recurrence with attention and became the foundation of modern language models. Self-attention lets every token in a sentence weigh its relevance to every other token. Large language models are trained to predict the next token on enormous amounts of text. Tokenization splits text into subword pieces that the model can map to embeddings. Sentence embeddings compress the meaning of a whole sentence into a single vector for search and clustering. Fine-tuning with human feedback aligns language models to be more helpful and less harmful. Retrieval-augmented generation lets a language model look up documents before it answers.

Reinforcement learning trains an agent to take actions in an environment to maximize long-term reward. The agent balances exploration of new actions against exploitation of actions it already knows are good. Q-learning estimates the value of taking each action in each state. AlphaGo combined deep neural networks with tree search to defeat the world champion at Go in 2016. A policy is the strategy that maps what the agent observes to the action it takes.

Machine learning systems can inherit bias from the data they are trained on. A hiring model trained on past decisions may repeat historical discrimination. Explainability tools like SHAP estimate how much each feature contributed to a prediction. Differential privacy adds carefully calibrated noise so that no individual's data can be recovered. Adversarial examples are inputs with tiny, invisible changes that fool a model into a wrong answer. Running models on-device keeps personal data private because nothing is sent to a server.
